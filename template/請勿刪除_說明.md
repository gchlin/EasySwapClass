# ⚠ template/ 請勿刪除

這個資料夾放的是 **UI 母檔**：

- `代課查詢_發布.html`：整個查詢網頁的「唯一 UI 真相來源」。
  所有產出（live/ 的網頁、各版單檔 HTML）都從它來。

## 為什麼重要

- 改網頁外觀 / 文字，**只改這個檔**。
- `live/index.html` 是它的逐字複本；各版 `代課查詢_單檔.html` 是它加上內嵌資料。
- 它**不含任何真實課表資料**，可安全進 git。

## 如果不小心刪掉了

不會永久遺失，依序可救回：

1. 用 git 還原：`git checkout template/代課查詢_發布.html`
2. 或開「更新課表.bat」→ 選 **[6] 修復母檔**：會自動從 `live/index.html`
   或最新的單檔 HTML 重建這個母檔。

請不要手動刪除本資料夾或其中的母檔。
